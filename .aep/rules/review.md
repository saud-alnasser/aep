# Rule — review

## What failure looks like here

| Area | It fails when |
| --- | --- |
| `src/` | a shipped surface disagrees with `specs.md`, or makes a checkable claim that `src/scripts/verify.mjs` does not assert |
| `src/` text | it cites something that does not exist in an installed repository, such as `specs.md` or a section number |
| `specs.md` | it describes behaviour `src/` no longer has |
| `src/scripts/` | a guard passes while the thing it checks is broken |

## Skip

- `.aep/` protocol-owned files: installer output. Review `src/` instead.
- `src/stamps.json`: written by `release.mjs`.
- `src/adapters/`: generated by `adapters.mjs`.
- `src/scripts/contract.mjs`'s path list: generated by `manifest.mjs`.

## Also

A word budget or hot-path failure in `aep check` is Important: it means every
run in every repository pays for the change.
